✈️ Telegram-бот · Python

Онлайн-запись в барбершоп за 30 секунд

BarberBook принимает записи 24/7: клиент выбирает услугу, день и свободное время, оставляет номер и получает напоминание. Администратор видит расписание и получает уведомления о каждой записи.

🗓Умное расписание

Свободные слоты считаются с учётом длительности услуги и уже занятого времени.

🔒Без двойных записей

Атомарная проверка слота: два клиента не займут одно и то же время.

⏰Напоминания

Фоновая задача присылает напоминание за 2 часа до визита.

🛠Админ-панель

Расписание по дням, выручка, статистика отмен, ручная отмена записи.
